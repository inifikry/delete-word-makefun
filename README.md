# The Word You'd Delete From the Dictionary

**Entry: `queue`**

Five letters, four of them silently standing in line behind the q.
Delete the word, end the queue.

## How it works

`main.py` writes the single word `queue` to `/output/entry.txt`.
Deterministic: no network, no randomness, no input.

```sh
python3 main.py
```
